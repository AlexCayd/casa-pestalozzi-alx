# Historial documental de reservaciones

Esta carpeta contiene documentos sustituidos o índices históricos. No define
reglas vigentes.

- `reservaciones_fuente_de_verdad_anterior.md`: versión normativa reemplazada.
- `../reporte_etapa4_motor_temporal.md`, `../reporte_etapa5_capacidad.md` y
  `../reporte_etapa6.md`: evidencias de etapas cerradas; se mantienen fuera de
  la fuente vigente para conservar trazabilidad sin competir con ella.
- `../../plan_estabilizacion_reservaciones.md`: historial de ejecución resumido
  y cerrado; la fuente normativa vigente es el archivo ubicado en la raíz.

Una regla funcional nueva debe editar primero
`reservaciones_fuente_de_verdad.md`; no debe agregarse aquí como contrato.
